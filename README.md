# DashDecode

Car dashboard warning lights guide: tap any symbol to learn its meaning, urgency and what to do. Red, amber and green zones explained. Free.

## Features
- Symbol atlas grid organized in red / amber / green urgency zones
- Tap any light for meaning, what-to-do steps and a drive-or-stop verdict
- Text search plus colour-filter chips across all 12 lights
